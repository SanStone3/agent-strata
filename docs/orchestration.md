# 编排与交付

主控保留用户目标和权限，决定直接完成还是委派，并对最终 diff、验证和交付负责。CLI/App 当前选择决定主控型号与强度；skill 不恢复旧值。

## 按任务选择

| 工作 | 起点 | 停止 / 升级条件 |
|---|---|---|
| 已知路径的小改动、顺序操作 | 主控直接工具 | 无需为单次读取创建 Agent |
| 代码定位、日志取证、提取、摘要、机械执行 | Luna low / medium | 需要判断实现契约或追查跨模块根因 |
| 需要读代码、修改并跑测试的普通功能、修复、重构 | Sol medium `worker` | 契约不明，或涉及安全、并发、迁移 |
| 改法已知、可快速验收的小改动 | Sol low 或显式选择 Terra medium | 首个有效检查暴露根因不明时交给 Sol |
| 有明确验收的写作、视觉和计算机操作 | Terra medium / high | 停滞后检查已有结果，再派发剩余工作 |
| 复杂实现、跨模块根因 | Sol high `deep_worker` | 不变量不明、证据冲突或回滚代价高时用 xhigh |
| 关键独立审查 | Sol xhigh `reviewer`，只读 | 报告有证据的缺陷，由主控处理 |

先按风险和验收难度确定模型能力要求。已知难题首轮交给 Sol。对满足要求的候选同时比较指数、单任务成本、耗时和输出 token。发现新问题时，先检查已完成的部分，再把剩余问题交给合适的模型。 [基准与成本依据](../skills/strata/references/cost-control.md)

## 并发与上下文

Strata 无固定数字上限。实际并发取宿主容量、有用独立任务、资源、成本与主控整合能力的最小值。默认一个写入者；多写入者需明确不相交路径、固定共享契约和独立检查。详细条件只维护在 [scaling.md](../skills/strata/references/scaling.md)。

给子任务紧凑任务包：目标、已知证据与文件指针、写域 / 只读范围、约束、验收、停止条件和结果预算。避免全历史 fork、重复探索和日志回灌。主控保存简短任务账本，复用有效证据；任务变更后根据当前状态重写下一包。[任务契约](../skills/strata/references/task-contract.md)。

例如并行检查两个不同风险面，同时由主控实现；写入完成后再审最终 diff。若审查依赖尚未完成的实现，就按顺序执行。独立不成立时，不用多开 Agent 掩盖缺失的决策。

子 Agent 不派生，不扩大范围，不自行提交 / 推送 / 部署，不调用另一个编码厂商。冲突先停受影响写入、检查真实状态，再串行修复。身份、额度或网络失败不触发轮流换模型。主控读回必要证据、运行允许的有效检查，交付实际结果与未验证项。

Claude Code 的模型 / effort 基线继续使用其 [独立原生策略](../skills/strata/references/claude.md)。
