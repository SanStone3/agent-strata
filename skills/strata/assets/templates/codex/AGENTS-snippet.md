## Layered Agent Orchestration

Read the shared `strata/SKILL.md` for meaningful independent work; keep trivial work local. Follow the current CLI/App primary model and effort, including user changes. Never write or restore primary settings during skill updates.

- Use task-aware Sol/Terra/Luna model and effort routing from the skill; do not duplicate a fixed model table here.
- No Strata numeric agent cap: use actual host slots, resource and synthesis capacity. Keep one writer by default. The budget caps concurrency, not total work. Raise the budget only for disjoint write domains, frozen contracts, independent checks and review capacity.
- Named custom roles use compact task packets or limited recent-turn forks. Never combine explicit custom type with full-history fork. Keep each child's creation model; refresh bindings only when the execution context changes.
- Scouts/reviewers are read-only. Subagents do not spawn descendants, commit, push, deploy, expand scope, or invoke another coding-agent provider. Preserve CODEX_HOME, authentication, provider, profile, permissions and user work.
- Return concise file/symbol evidence, checks and uncertainties. The controller inspects writes and integrates results.
